# Revision protocol amendment: within-study target-access comparisons

Date: 2026-09-06

## Rationale

To assess target-access differences while holding architecture and feature extraction fixed, the revision adds a within-study matched comparison. This analysis was not part of the original synthesis plan. It is therefore identified as a dated post-hoc protocol amendment and is kept separate from the prespecified random-effects meta-analysis.

## Eligibility rules fixed before extracting comparison values

A comparison was eligible when all of the following could be verified in the primary report:

1. Both arms used the same dataset, task, metric, subject-disjoint split, and model backbone.
2. The comparison removed the domain-adaptation or target-data mechanism while retaining the remaining architecture and experimental settings.
3. Exact numerical results were reported for both arms.
4. The target-access arm did not use target emotion labels. Supervised or few-shot calibration was excluded from this comparison.
5. The no-adaptation arm was not evaluated with a subject-mixed split.

Comparisons were excluded when the nominal ablation removed only one of several target-dependent components, when different models or feature pipelines were compared, when target-statistic use remained in both arms, when only a graph without exact values was available, or when the no-adaptation arm used a different evaluation split.

## Synthesis rule

The eligible reports did not provide paired subject-level scores or the covariance between arms. Multiple sessions and tasks from the same report are statistically dependent. Consequently, the amendment reports arm means, percentage-point differences, direction, median, and range as a matched descriptive case series. It does not calculate an inverse-variance pooled effect, a paired confidence interval, or a causal estimate.
