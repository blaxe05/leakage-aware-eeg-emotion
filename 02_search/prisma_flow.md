# PRISMA 2020 Flow

This file records the frozen study-selection counts used in the manuscript and
Figure 1. Database searches covered English-language records from 2010 through
14 May 2026.

## Identification

| Database | Records |
|---|---:|
| IEEE Xplore | 251 |
| Web of Science | 656 |
| Scopus | 616 |
| PubMed | 141 |
| **Total records identified** | **1,664** |

Records were deduplicated by exact DOI, followed for DOI-less records by
normalized title, first-author surname, and publication year.

| Identification result | Count |
|---|---:|
| Records identified | 1,664 |
| Duplicate records removed | 887 |
| Unique records screened | 777 |

## Screening And Eligibility

| Selection stage | Count |
|---|---:|
| Unique title/abstract records screened | 777 |
| Records excluded at title/abstract screening | 130 |
| Reports assessed or sought for eligibility | 647 |
| Full-text exclusions, unavailable reports, queued reports, and records removed from the active analysis | 243 |
| Active full-text-verified studies included in qualitative synthesis | 404 |
| Active extracted result rows | 672 |
| Studies included in quantitative synthesis | 98 |
| Meta-eligible result rows | 198 |

The flow reconciles as follows:

- `1,664 - 887 = 777` unique records screened.
- `777 - 130 = 647` reports assessed or sought.
- `647 - 243 = 404` active full-text-verified included studies.
